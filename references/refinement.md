# 精修判断与命令

## 图形界面的一轮操作

1. 在 Olex2 中打开试验副本的 RES 或 INS。展开 **Work → Refine**，确认精修程序和方法。运行第一次 Refine，查看日志中实际读取的 HKL、反射数、警告和残差。将此目录留作基线。
2. 在新副本中选择待检查的原子，显示原子标签、热椭球和 Q 峰。转动结构，测量峰至邻近原子的距离。对靠近晶胞边界的原子显示对称邻居，判断峰是否已经由另一不对称单元解释。
3. 先改一个局部问题。例如对疑似无序的末端，记录原始占位和最近 Q 峰，在有连续密度的位置建立第二构象。在模型指令中检查两组 PART、占位变量和 AFIX 的作用范围，必要时用 PART 0、AFIX 0 结束相应分组。
4. 再次 Refine。对照同一区域的差值峰、椭球、键长、占位不确定度和日志中的参数相关性。若次组分趋近零、坐标漂移或出现非正定 ADP，回到上一个保存点，重新评估该构象。
5. 对最终选定模型输出包含精修结果的 CIF 与结构因子 FCF。把新生成的 RES 放入另一干净目录，配上对应 HKL 和依赖文件重跑，再依照核验清单交付。

## 先建立可比较的模型

在原引擎下复现基线。选择 `olex2.refine` 时记录方法及版本。已有 SHELXL 或其他引擎的工程若改用新引擎，要把切换引擎本身作为独立试验。Olex2 命令行的 `refine 8 20` 表示请求最多 8 轮精修并寻找 20 个差值峰。检查日志中的实际轮数和异常，并以同轮的 RES、FCF 和 CIF 为准。[Olex2 官方精修说明](https://www.olexsys.org/olex2/docs/tasks/tasks/structure-refinement/)

| 观察 | 在工作副本中的操作 | 接受修改所需的证据 |
| --- | --- | --- |
| 预期元素与现有标注冲突 | 查看局部键长、配位环境、差值峰和 ADP；在同一组数据上比较两个归属 | 新归属符合化学环境，局部差值和 ADP 合理，新的异常均有解释 |
| 重原子附近出现差值峰或椭球拉长 | 同时检查吸收校正、孪晶、对称相关位点与无序；在不同差值图等高线上查看是否存在连贯片段 | 峰构成可解释的第二位置，且占位、几何和参数稳定 |
| 末端基团可能有两种构象 | 复制有密度支持的分支，设置 PART，保留共有原子于 PART 0；用一个自由变量关联互补占位 | 次组分具有合理精度与 ADP，键长和对称近接触合理，H 随母原子占位 |
| 多于两种构象 | 只在物理上互斥且应填满的位点约束总占位；记录自由变量、SUMP 目标及标准不确定度、引擎的解释方式 | 检查实际占位及其和、相关性和参数数目；在新的进程中复算 |
| 孤立高峰靠近芳香环或杂原子 | 核对母体结构、键合方向、可能的替代构象或对称邻居；对目标结构式显示无取代的位点尤其谨慎 | 有可解释的连接、键长和稳定占位，且差值图支持 |
| 氢原子缺失或位置可疑 | 先完善非氢模型，再按化学环境添加 riding H。对于 OH、NH 和可互变异构的杂环，检查差值图、供受体环境及接触 | 氢数、价态、几何、Uiso 与母原子一致；区分理想化位置和差值图定位 |

适量使用几何与位移参数限制。SADI 关联预期相似的距离，DFIX 指定有依据的目标距离；RIGU、SIMU 分别用于刚性键行为和邻近原子的 ADP 相似性。EADP 将位移参数严格相等，采用时须能解释其物理依据。逐步放松限制，记录哪些限制维持了模型稳定以及次组分是否由数据支持。

## 显式溶剂与掩膜

1. 先完善主体。检查溶剂空穴与对称相关位置中的连续密度、几何和占位。对于已知结晶溶剂，单独检验能否辨认末端、主链及其构象。母液成分只给出候选身份。
2. 当局部密度不足以稳定确定原子位置时，在新的试验目录计算溶剂掩膜。检查空穴边界是否吞入主体或显式溶剂，记录每类空穴的体积、电子数、重数及数值的归一化基准。将每晶胞总电子数除以 Z，得到每化学式单位的估算，再与候选分子的电子数比较。
3. 比较显式模型与掩膜模型时使用相同反射和已记录的权重，同时考察原子级解释、差值图和拟合指标。说明所选模型的局限。已知培养溶剂且电子数相符可以支持推定归属；精确化学计量仍需相应证据。
4. 记录掩膜来源并保留同轮 FAB、SQF 及 mask 日志。最终固定选定 FAB 做复算。改动主体、晶胞、空间群、反射设置或溶剂边界后要重新评估掩膜。报告显式原子和掩膜计入的成分，保持化学式、Z、F(000)、密度及 CIF 说明的采用口径一致。
